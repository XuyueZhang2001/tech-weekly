把本机凭据写进 GitHub Secrets

前面的「本机凭据」只对你本机生效。如果你打算让 GitHub Actions 定时发信， 还需要把同样的值写进仓库的 Secrets——这一步以前只能去网页上一个个点，现在可以一键完成。

Token 怎么来
  1. 打开 github.com/settings/tokens/new，选 classic token
  2. Scopes 勾上 repo（写 Actions Secrets 需要它）
  3. 生成后粘贴到上面。用完可以直接在页面里删掉，本工具不会保存它

写入的值会先用仓库公钥加密（libsodium sealed box），再交给 GitHub——和网页上手动填写完全等价。
